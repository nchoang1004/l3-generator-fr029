# ADR-2026-006 — Tài liệu API của FR-029: model đề xuất dữ kiện, code kiểm bằng chứng

- **Trạng thái:** draft. Chưa ký Architecture Gate. Chờ [OQ-L3GEN-018](../../lifecycle/change-sets/CHG-L3GEN-2026-002/open-questions/OQ-L3GEN-018.md) (ranh giới của bộ kiểm).
- **ADR này viết sau khi đã quyết và đã có code.** Hoàng chọn "agent thuần" ngày 07/10/2026 ([CR-L3GEN-2026-008](../../evidence/requests/CR-L3GEN-2026-008.yaml)); code của luồng agent và bộ kiểm viết từ 07/10 tới 09/10/2026. Giống [ADR-2026-005](ADR-2026-005.md), tiêu chí ở mục 3 lập khi viết ADR, sau khi đã chọn. Người ký cần biết đây là bản ghi lại quyết định đã có, không phải phương án còn mở.

## 1. Vấn đề

FR-L3GEN-029 cần tài liệu API đúng tới từng trường: method, path đủ prefix, tham số, model, status, dependency, lời gọi HTTP ra ngoài, mỗi giá trị kèm `file:dòng`. Thiết kế hiện hành giao việc này cho [CMP-L3GEN-004](../l2/CMP-L3GEN-004.md) "Trích dữ kiện": code tự đọc cây cú pháp và sinh dữ kiện. Mục 8 của chính CMP-004 ghi nhiều chỗ code tĩnh chưa làm được, ví dụ 004-1 (hai tập route lệch nhau), 004-3 (0/7 repository có dữ kiện HTTP ra ngoài). Mỗi kiểu viết FastAPI mới lại cần thêm một luật.

## 5. Quyết định

Chọn **C** cho FR-L3GEN-029.

- Model, qua công cụ đọc file có số dòng, đề xuất mọi dữ kiện API. Code không trích dữ kiện API từ cây cú pháp (`DP` chặn bằng test, quy tắc 1.3 trong `docs/FR029-quy-tac.md`).
- Code kiểm từng đề xuất trước khi nhận. Bộ kiểm làm đúng 3 việc:
  1. **Từ chối** đề xuất có bằng chứng không chứng minh được giá trị (dòng không chứa điều được khai, URL không phải đối số URL, route không đăng ký dưới app được khai, prefix sai thứ tự…).
  2. **Đánh dấu dòng nghi ngờ** (trông như route, đăng ký route, lời gọi HTTP) mà agent phải nộp mục hoặc bác kèm lý do.
  3. **Nhắc** tham số và dependency mà dependency của route khai nhưng agent chưa nộp.
- Bộ kiểm **không tạo mục**: không có đường code nào biến kết quả phân tích tĩnh thành route, tham số hay lời gọi HTTP trong tài liệu. Ranh giới này là đề xuất, chờ [OQ-L3GEN-018](../../lifecycle/change-sets/CHG-L3GEN-2026-002/open-questions/OQ-L3GEN-018.md).

FR-028, FR-030, FR-031 không đổi theo ADR này.
